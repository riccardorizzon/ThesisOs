## Legenda esito

| Esito | Significato |
|-------|-------------|
| **S** | Success — criterio di successo pienamente soddisfatto |
| **P** | Parziale — progresso ma criterio non completo |
| **F** | Failure — bloccato o abbandona |
| **N/T** | Non testato — tempo esaurito o dipendenza non soddisfatta |

**Fiducia (1–5):** quanto si sente sicuro di aver capito cosa fare *dopo* il task  
1 = perso · 3 = incerto · 5 = sicuro

**Primo punto di esitazione:** dove **inizia a dubitare** — prima del fallimento finale.

**Osservazione pura** (durante la sessione — niente soluzioni):

|-------|--------|
| Cosa voleva fare | |
| Cosa ha fatto realmente | |
| Cosa si aspettava | |
| Dove si è fermato | |
