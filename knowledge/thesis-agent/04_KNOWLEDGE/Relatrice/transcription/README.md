## Temi ricorrenti della relatrice (sintesi proposta)

- **Citazioni:** prima occorrenza con **nome completo**, poi solo cognome; nomi completi
  per stilisti (Balenciaga, McQueen, Vionnet); citazione in forma (Autore, anno).
- **Attribuzione vs interpretazione:** segnalare quando un'affermazione è intuizione
  dell'autrice ("è tuo questo testo? Se no, cita!"; "questo è una tua appropriazione?").
- **Struttura:** separare concetti in più paragrafi; evitare ripetizioni.
- **Autori suggeriti / da valutare:** Bourriaud (estetica relazionale), Fayga Ostrower,
  Munari, eventuale contestualizzazione di U. Eco.
- **Tono generale:** prevalentemente positivo ("ottimo!", "tutto ok, fai attenzione in stesura").
