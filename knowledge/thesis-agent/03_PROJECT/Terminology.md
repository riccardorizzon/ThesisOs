# Terminology

Lessico stabile del progetto. Proporre modifiche via MEMORY UPDATE.

## Oggetto e metodo

| Termine | Uso | Evitare |
|---------|-----|---------|
| Processo creativo | Oggetto teorico centrale | "creatività" generica senza contesto |
| Fashion design contemporaneo | Ambito disciplinare | "moda" colloquiale |
| Caso applicativo / caso di studio | STIGMATA nel testo | "progetto principale", "oggetto della ricerca" per STIGMATA |
| Framework teorico | Mappa concetti (THEORY MAP) | "teoria definitiva" |

## STIGMATA

| Termine | Uso |
|---------|-----|
| STIGMATA | Nome proprio collezione; maiuscolo |
| Documentazione di processo | Foto, sketch, appunti, render archiviati |
| Fase / tappa | Step del processo creativo documentato |

## Epistemologia (etichette di lavoro)

| Termine | Significato |
|---------|-------------|
| FATTO | Dato attribuibile a fonte |
| INFERENZA | Collegamento esplicito tra fatti |
| VALUTAZIONE CRITICA | Giudizio argomentato |
| FONDATO / PLAUSIBILE / SPECULATIVO | Livelli forza attribuzione |

## Separazione A / B

| Termine | Significato |
|---------|-------------|
| Parte A | Dati dell'autore (cosa dice la fonte) |
| Parte B | Applicazione alla tesi o a STIGMATA |

## Fonti

| Termine | Significato |
|---------|-------------|
| Corpus attivo | Autori in BIBLIOGRAPHY_MASTER approvati |
| Fonte candidata | In valutazione |
| Fonte scartata | Esclusa con motivazione |

## Stati documento

| Termine | Significato |
|---------|-------------|
| Bozza | Prima stesura non sottoposta a revisione |
| PRONTO PER REVISIONE | Completo; attende feedback |
| Congelato | Approvato; non modificare senza trigger esplicito |

## Autori (riferimento rapido — non sostituisce bibliografia)

Usare forme bibliografiche del master (es. Seivewright, Sennett, Löbach, Albers,
Benjamin, Hollander, Csikszentmihalyi). Per Warburg e filone iconografico: allinearsi
a sezione dedicata nel CORE THEORY MAP.
